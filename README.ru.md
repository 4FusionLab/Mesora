## Измерения в контексте модели

Откройте **Design → Solid → Inspect → Mesora — Add Dimension**, выберите геометрию и соберите таблицу измерений. Можно заменить геометрию строки, выбрать совместимый тип, настроить смещение или удалить строку. **OK** сохраняет определения и видимость в модели; **Cancel** отменяет черновик.

В зависимости от выбранной геометрии доступны **Distance**, **Angle**, **Edge Length**, **Radius**, **Diameter**, **Area** и **Perimeter**. Для расстояния и угла нужны два совместимых объекта, для остальных типов — один поддерживаемый объект. Значения пересчитываются по актуальной геометрии после команд изменения модели.

У каждой строки есть глазик. Глазик рядом с **+**, **−** и корзиной скрывает или показывает весь набор, сохраняя индивидуальные настройки. Mesora разносит подписи при добавлении или изменении размеров. При вращении и масштабировании их положение и выносные линии остаются на месте в модели; меняется только ориентация текста для чтения. **Refresh Dimensions** размещает подписи для нового ракурса.

## Сохранение и возврат к модели

Определения, ссылки на геометрию, смещения и видимость хранятся вместе с моделью. Сохранение убирает отображаемую графику, чтобы она не попала в сохранённую модель. После сохранения откройте Mesora или нажмите **Refresh Dimensions**, чтобы снова показать размеры. Открытие документа или запуск Mesora восстанавливают сохранённый набор.

Без работающей Mesora модель остаётся доступной для редактирования, а размеры не показываются. Измерения информационные и не создают управляющих ограничений. См. [видимость, сохранение и Drawing](docs/visibility-and-drawing.ru.md).

## Установка

1. Скачайте ZIP со страницы [GitHub Releases](https://github.com/4FusionLab/Mesora/releases) и распакуйте его в постоянную папку.
2. В Fusion откройте **Utilities → Scripts and Add-Ins → Add-Ins**. Нажмите **+ → Script or add-in from device** и выберите папку `Mesora` с файлами `Mesora.py` и `Mesora.manifest`.
3. Выберите **Mesora → Run** и включите **Run on Startup**.
4. Откройте модель и выберите **Design → Solid → Inspect → Mesora — Add Dimension**.

Не перемещайте распакованную папку, пока Fusion использует аддон. Для готового архива отдельная установка Python не нужна.

## Совместимость

Нативная приёмка macOS охватила типы измерений и реальный выбор/переключение типов, видимость, Undo/Redo, обновление модели, сохранение и повторное открытие, Save As, переход в Drawing, обычный перезапуск Fusion, работу без аддона и установку ZIP. Воспроизведённые случаи наложения и скачков подписей прошли повторную проверку. См. [доказательства приёмки](docs/validation/stability-native-2026-11-13.ru.md).

Манифест поддерживает Windows и macOS. **Нативная проверка Windows Fusion не проводилась.** Завершённый рабочий чертёж и все возможные ошибки/восстановление облачного сохранения не входят в принятую область; подробные [границы проверки](docs/fusion-safety.ru.md) отделяют эти ограничения от подтверждённого поведения.
