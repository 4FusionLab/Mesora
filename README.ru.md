## Измерения в контексте модели

Откройте **Design → Solid → Inspect → Mesora — Add Dimension**, выбирайте геометрию и собирайте таблицу измерений. У строк есть идентификаторы, например `m1`: можно изменить геометрию, выбрать совместимый тип измерения, настроить отступ и удалить строку. Подтвердите команду, чтобы показать размеры. У каждой строки есть глазик; глазик рядом с **+**, **−** и корзиной управляет всем набором, сохраняя индивидуальные настройки. **OK** записывает определения и видимость в модель; **Cancel** отменяет черновик. В меню Mesora также доступны показ и скрытие, обновление и удаление размеров.

В зависимости от выбранной геометрии доступны **Distance**, **Angle**, **Edge Length**, **Radius**, **Diameter**, **Area** и **Perimeter**. Для расстояния и угла выбираются два совместимых объекта, для остальных типов — один поддерживаемый объект. Доступные варианты зависят от выбора; неподдерживаемые сочетания отклоняются.

## Установка опубликованной экспериментальной версии

1. Скачайте `Mesora-1.0.0.zip` со страницы [экспериментального релиза](https://github.com/4FusionLab/Mesora/releases/tag/v1.0.0) и распакуйте архив в постоянную папку.
2. В Fusion откройте **Utilities → Scripts and Add-Ins → Add-Ins**. Нажмите **+ → Script or add-in from device** и выберите папку `Mesora` с файлами `Mesora.py` и `Mesora.manifest`.
3. Выберите **Mesora → Run**. В изолированной тестовой среде включите **Run on Startup**; пока аддон включён, учитывайте предупреждение выше.
4. Откройте тестовую модель и выберите **Design → Solid → Inspect → Mesora — Add Dimension**. Укажите один или два объекта для строки, проверьте совместимый тип и предпросмотр, затем подтвердите команду.

Не перемещайте распакованную папку, пока Fusion использует аддон. Для готового архива отдельная установка Python не нужна.

## Статус и ограничения

- В текущих исходниках кандидата **OK** записывает ссылки на геометрию, типы измерений, смещения и индивидуальную/общую видимость в `Design.attributes`. Значения заново вычисляются по геометрии. Неподдерживаемые или повреждённые данные не перезаписываются молча. Наличие этой реализации не подтверждает безопасность сохранения модели.
- После завершения команды Fusion обновление ставится в очередь через custom event в разрешённом потоке Fusion. Определения загружаются при открытии документа или запуске Mesora; отложенный показ ограничивается состоянием документа, рабочей среды и команды. Штатный запуск на macOS восстановил видимость, смещения и актуальные значения после изменения и сохранения геометрии без Mesora. Полная приёмка параметрического обновления не завершена.
- Обработчик сохранения через UI удаляет отслеживаемую графику и намеренно не пересоздаёт её в `documentSaved` или при активации рабочей среды. После сохранения откройте Mesora или нажмите **Refresh Dimensions**, чтобы вернуть размеры. Штатные GUI Save и Save As подтвердили очистку; отмена Save As сохранила текущие размеры. Изоляция копии и все пути сохранения/восстановления ещё требуют приёмки.
- GUI-проверки macOS подтвердили индивидуальную/общую видимость, применение глазиков и проверенный путь сохранения/повторного открытия без аддона: при остановленной Mesora размеров не было. Undo/Redo восстанавливали метаданные видимости, но Undo вернул неотслеживаемую группу графики, а отложенная перерисовка добавила дубликат: графическая приёмка Undo не пройдена. Нужны исправление очистки и повторная нативная проверка. Прежний постоянный артефакт из другого пути загрузки/API требует отдельного повторного прогона. Предыдущая проверка Drawing не подтверждает Drawing на актуальном кандидате с сохранением определений и обновлениями. Трансформированные/вложенные экземпляры и более широкие сценарии выбора и отображения также требуют проверки. Автономные тесты не подтверждают приёмку в Fusion.
- В манифесте заявлены Windows и macOS. Очистка графики Undo с повторной нативной проверкой, приёмка Windows, полный перезапуск Fusion, актуальный Drawing, параметрические изменения и оставшиеся пути сохранения/восстановления ещё не пройдены. До их прохождения кандидат остаётся экспериментальным.

## Разработка и поддержка

Исходники аддона находятся в `Mesora/`. Автономные тесты и локальная сборка:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_project.py
python3 scripts/build.py --version 1.0.0
```
