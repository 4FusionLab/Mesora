# Рабочий отчёт: Drawing и видимость размеров, 13.11.2026

## Причина сбоя

На исходном коде воспроизведено повторное сохранение тестового цилиндра при
создании Drawing. Обработчик `documentSaved` вызывал `State.refresh()`, создание
CustomGraphics снова помечало модель изменённой. Команда
`NewFusionDrawingDocumentCommand` повторяла сохранение; версии тестового файла
росли, интерфейс зависал. На промежуточном исправлении обнаружен риск такого же
восстановления при активации исходного документа, поэтому автоматическое
восстановление удалено и из этой точки. Пользовательские модели не открывались.

## Итоговое поведение

- Перед сохранением удаляется графика, включая живой предпросмотр.
- В `documentSaved`, при активации документа и рабочей среды графика не создаётся.
- После сохранения размеры возвращаются явным действием: открытием команды Mesora
  или `Refresh Dimensions`. Настройки измерений остаются в памяти текущей сессии.
- Обработчик камеры пропускает Drawing и переходы между рабочими средами.
- Глазик строки меняет только видимость; общий глазик сохраняет настройки строк.
- Глазики используют BoolValueCommandInput с постоянным состоянием и явный
  `doExecutePreview()`, чтобы результат сразу отображался.

## Проверено на финальном коде в macOS Fusion

- Штатная загрузка после перезапуска; установлены 12 обработчиков уровня аддина.
- Окно с двумя измерениями: Edge Length и Radius; глазики у строк и на панели.
- Настоящее нажатие глазика первой строки: `m1.visible=False`, `m2.visible=True`,
  одна валидная группа предпросмотра; обе строки сохранены.
- Общий глазик: `visible=False`, ноль групп предпросмотра, две строки.
- Повторный общий показ: `visible=True`, одна группа; первая строка скрыта,
  вторая видима. Индивидуальное скрытие не сброшено.
- Cancel: исходное состояние восстановлено, hidden_ids пуст, две группы.
- Создание Drawing с показанными размерами: исходник v162 -> v163 за одно
  сохранение; активны `FusionDocumentationEnvironment`, `adsk::drawing::Drawing`
  и `FusionDrawingViewBaseCommand`. Исходная модель чистая, групп Mesora нет.
- Возврат в модель: `FusionSolidEnvironment`, до явного обновления документ чистый;
  `State.refresh()` без ошибок восстановил две группы. Зависания нет.
- Тестовые окна закрыты без сохранения чертежа; синтетический исходный файл
  сохранён для воспроизведения. На ранних неудачных прогонах он накопил версии.

## Автоматическая проверка

74 теста проходят, `scripts/check_project.py` проходит, `git diff --check` чистый.
Регрессионные тесты проверяют запрет пересоздания графики после сохранения и
активации, пропуск Drawing обработчиком камеры, скрытие без потери определений,
применение и отмену видимости, глобальное скрытие и восстановление.
Локальный ZIP 1.1.0 проверен по манифесту, исходникам, четырём иконкам скрытого
глазика и SHA-256. Это локальный кандидат, не опубликованный релиз.

Windows Fusion не проверялся. Применение скрытия через OK и повторное открытие
проверены офлайн; нативный прогон видимости покрывает предпросмотр и Cancel.
Полная матрица save/reopen, сбой сохранения и Undo/Redo остаётся вне этой проверки.
В Drawing наблюдались диагностические ошибки установленного Paramood NO_DESIGN;
его код не изменялся и успешным результатом Mesora они не считаются.
