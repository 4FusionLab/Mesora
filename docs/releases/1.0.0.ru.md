# Mesora 1.0.0

[English](1.0.0.md)

Экспериментальный аддон Fusion для информационных 3D-измерений на время сеанса. Выбирайте геометрию в команде Mesora, чтобы создавать и редактировать строки измерений; команды видимости, обновления и очистки управляют графикой.

**Используйте только тестовые документы.** Безопасность сохранения и повторного открытия с CustomGraphics не подтверждена; не сохраняйте ценные модели при включённой Mesora. Измерения теряются при остановке аддона или закрытии документа. Автономные тесты не подтверждают совместимость в самом Fusion. Windows, трансформированные и вложенные экземпляры и полный сценарий сохранения и повторного открытия остаются непроверенными. Подробности — в README и `docs/fusion-safety.ru.md`.
