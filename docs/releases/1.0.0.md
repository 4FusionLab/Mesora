# Mesora 1.0.0

Experimental Fusion add-in for session-only informational 3D measurements. Select geometry in the Mesora command to create and edit measurement rows, and use the visibility, refresh and clear commands to manage the graphics.

**Use disposable documents only.** CustomGraphics save/reopen safety is not established; do not save valuable designs while Mesora is enabled. Measurements are lost when the add-in stops or the document closes. Offline tests do not establish native Fusion compatibility. Windows, transformed and nested occurrences, and full save/reopen behavior remain unverified. See the README and `docs/fusion-safety.md` for details.
