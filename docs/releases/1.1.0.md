# Mesora 1.1.0

[Русская версия](1.1.0.ru.md)

Measurement definitions now stay with the Fusion design. Mesora restores references, offsets and row/global visibility, and calculates values from the current geometry. A design saved with this version can be opened and edited without Mesora; its Mesora annotations are not displayed while the add-in is absent.

- Saved definitions for Distance, Angle, Edge Length, Radius, Diameter, Area and Perimeter.
- Automatic updates after model commands, including geometry Undo/Redo.
- Separate caption placement for the visible set; positions and angular geometry stay fixed while orbiting and zooming.
- Ownership-based cleanup prevents duplicate graphics after Undo. Closing a command releases its temporary handlers and document references.
- Missing references remain editable instead of blocking the entire measurement table. Unsupported or damaged metadata is not silently overwritten.

Saving removes session graphics to keep the saved model clean. Open Mesora or run **Refresh Dimensions** to show them again. The definitions remain in the design.

Validated with 144 offline tests, packaging checks on Linux/macOS/Windows, and native macOS Fusion acceptance. Native Windows Fusion has not been tested. The native checks include seven measurement types, actual picker/type-change events, nested transformed references, Drawing creation, restart and use without the add-in. See the [acceptance matrix](../validation/stable-release-cjm-2026-11-13.ru.md) for the exact scope and limits.

Extract the versioned ZIP, add its `Mesora` folder in **Scripts and Add-Ins**, run the add-in and enable **Run on Startup**.
