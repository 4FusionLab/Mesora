# План реализации команды измерений Mesora

Цель: за один запуск создавать независимые сеансовые измерения с понятными ID и выбором совместимого типа.

1. Проверить и дополнить геометрический адаптер площадью и периметром грани; протестировать совместимость и единицы.
2. Вынести группировку последовательных выборов и ID в проверяемую модель; покрыть незавершённую пару точек, удаление и переключение типов.
3. Построить нативную таблицу Fusion и общий селектор, подключить предпросмотр, проверку и атомарное применение без потери сеансовых данных.
4. Дополнить отображение ID и измерений граней, не перезаписывая параллельные изменения выносов.
5. Запустить автономные тесты и проверить интерактивную команду на временном несохраняемом документе; указать оставшиеся ограничения.

Ограничения: не менять пользовательский документ, не перезапускать аддон без пользователя, не сохранять временные документы, не публиковать изменения.
