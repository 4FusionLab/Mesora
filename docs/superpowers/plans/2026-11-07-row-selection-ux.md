# Выбор геометрии для каждого измерения

Цель: отдельный выбор, очистка и удаление каждого измерения без случайного создания строк повторными кликами.

1. Заменить глобальный выбор набором секций Fusion, по одной на измерение: первая геометрия, при выборе точки — вторая точка, тип, результат и удаление. Новая строка добавляется явно; пустые строки не блокируют готовые измерения, неполная пара точек не подтверждается.
2. Сохранять выбор и тип независимо для каждой строки; предотвращать одинаковые готовые измерения, разрешая разные типы на одной грани.
3. Для подписей граней предпочесть проекцию глобальной оси на касательную плоскость, сохраняя переворот к камере и плоскость выноски.
4. Проверить автономные сценарии, затем интерфейс и вращение вида в отдельном временном документе Fusion. Не сохранять и не менять пользовательскую модель, не перезапускать аддон без необходимости; сохранить текущие сеансовые измерения.
