# Разработка Mesora

[English](DEVELOPMENT.md)

`Mesora/Mesora.py` отвечает за команды и события, `Mesora/renderer.py` — за графику,
а `Mesora/dimensions/` содержит логику измерений, сохранения и размещения. Корневой
каталог `dimensions/` — исторический автономный код; поставляемый пакет — `Mesora/`.

## Проверки и сборка

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_project.py
```

Собирайте с числовой версией, рассчитанной GitVersion 6.8.2, например после
записи этого результата в `MESORA_PACKAGE_VERSION`:

```sh
python3 scripts/build.py --version "$MESORA_PACKAGE_VERSION"
```

Сборщик создаёт детерминированный ZIP и SHA-256 в `dist/`, записывая версию
манифеста в архив без изменения checkout. Проверяйте манифест, содержимое архива,
checksum и release notes вместе. CI проверяет Linux, macOS и Windows, но не
запускает Fusion. Принятый runtime прошёл 144 автономных теста и
[CI run 15](https://github.com/4FusionLab/Mesora/actions/runs/43475119273).
Пакет из 56 файлов установлен и проверен в macOS Fusion.

## Контракты runtime

- Явное подтверждение сохраняет ссылки, типы, смещения и видимость через
  `dimensions/runtime_persistence.py`. Схема v2 читает v1; неизвестные, повреждённые
  и будущие данные нельзя молча перезаписывать. Значения пересчитываются по геометрии.
- Команды модели ставят обновление в очередь через `commandTerminated` и custom
  event. Открытие/запуск загружают определения; активация продолжает существующий
  запрос восстановления. Рендер разрешён только в подходящем контексте Fusion.
- Refresh/save/stop сверяют собственную графику по ID, включая новые wrappers,
  восстановленные Undo. Сохраняйте группы других аддонов и staged-графику команды.
- Размещайте подписи при явном предпросмотре, подтверждении, обновлении модели и
  восстановлении. События камеры лишь ориентируют текст: не переразмещают подписи
  и не перестраивают угловые дуги.
- Сохранение удаляет графику и снимает запрос восстановления. Не создавайте её
  заново в `documentSaved`; явные Mesora/Refresh возвращают показ после сохранения.
- Удерживайте активные обработчики и отключайте command scopes при уничтожении.
  Cancel возвращает подтверждённый набор без применения черновых глазиков или смещений.

## Нативная приёмка

Финальный независимый review не нашёл открытых Blocker или Major в согласованной
macOS-области выпуска. Нативная проверка типов подтвердила 13 настоящих UI-событий;
Inspect той же цилиндрической грани показал Loop Length 339,292 mm, Area 5089,38 mm²,
Radius 27 mm и Diameter 54 mm — значения совпали с Mesora. Прежние доказательства
также охватывают владение графикой Undo/Redo, обновление модели/Undo/Redo,
сохранение/повторное открытие, Save As, переход в Drawing, обычный перезапуск,
измерения вложенных/трансформированных ссылок и работу без Mesora. Воспроизведённый
случай наложений/скачков подписей прошёл приёмку пользователя.

Соблюдайте границы: проверка транзакции изменения параметра не является приёмкой
ручного Change Parameters UI, а проверка Drawing отменяла размещение Base View.
Windows Fusion, восстановление после реального сбоя облачного сохранения и
исчерпывающие сочетания геометрии/выбора остаются непроверенными. Недоступность
Windows не является отдельным блокером выпуска в принятой macOS-области. См.
[границы проверки](fusion-safety.ru.md), [нативные доказательства](validation/stability-native-2026-11-13.ru.md)
и [трассировку](validation/stable-release-cjm-2026-11-13.ru.md).

Для новых регрессий используйте синтетические документы. Сохранённые приёмочные
фикстуры удалены; соблюдайте действующее указание пользователя не сохранять CAD,
а не создавайте новые облачные файлы. Доказательство событий требует observer,
запущенного штатным аддоном Fusion. Прямой импорт через MCP не дал callback
observer и не доказывает их отсутствие у штатного продукта. Скрипты development
observer/driver исключены из ZIP.
