# Разработка Mesora

[English](DEVELOPMENT.md)

`Mesora/Mesora.py` содержит команду Fusion и обработку жизненного цикла событий; `Mesora/renderer.py` отвечает за графику, а `Mesora/dimensions/` — за логику измерений и размещения. Каталог `dimensions/` в корне сохранён как исторический автономный код; поставляемый пакет — `Mesora/`.

## Автономные проверки и пакет

```sh
python3 scripts/check_project.py
python3 -m unittest discover -s tests -v
python3 scripts/build.py --version 1.0.0
```

Сборщик создаёт детерминированный ZIP и SHA-256 в `dist/`. Версия манифеста записывается в архив без изменения файлов рабочего каталога. CI проверяет Linux, macOS и Windows, но не запускает Fusion.

## Статус кандидата и сохранение определений

Текущие исходники — экспериментальный кандидат для проверки, а не принятый
стабильный релиз. Явное подтверждение команды сохраняет ссылки и настройки в
атрибутах модели через `dimensions/runtime_persistence.py`; значения
пересчитываются. Схема v2 поддерживает все текущие типы измерений и читает схему
v1. Неизвестные, повреждённые или будущие данные нельзя молча перезаписывать.
Автоматическое обновление модели использует `commandTerminated` и отложенный
custom event. Загрузка при открытии документа и запуске запрашивает восстановление;
активация продолжает существующий запрос, а сохранение снимает его. Штатная
GUI-проверка macOS подтвердила восстановление при запуске/повторном открытии,
применение видимости, очистку в Save/Save As и отмену Save As. Undo/Redo
восстанавливали метаданные видимости, но графическая приёмка Undo провалена:
возвращённая неотслеживаемая группа и отложенная перерисовка дали две реальные
группы при одной в State. Нужны исправление очистки и нативная перепроверка.
Проверенная модель открывалась без размеров при остановленной Mesora, оставалась
доступна для изменения/сохранения и восстанавливала актуальные измерения после
запуска Mesora.

Прежний постоянный артефакт получен в другом пути загрузки Python/API и не
доказывает неисправность текущего штатного пути GUI-сохранения. API Save/Save As
нужно отдельно повторить со штатным запуском. Ручной **Refresh Dimensions** после
сохранения остаётся обходным путём; полная приёмка сохранения/восстановления не завершена.

Для независимого доказательства событий запускайте development observer через
штатный жизненный цикл аддона Fusion с помощью `scripts/prepare_native_observer.py`.
Прямой импорт через MCP не дал callback наблюдателя и не доказывает их отсутствие
у штатного продукта. Оба скрипта observer не входят в поставляемый аддон.

Параметрическая приёмка прервалась при чтении CUA дерева доступности Change
Parameters; наблюдаемый AX/Qt-стек не устанавливает причинность Mesora. Запрошено
ручное восстановление без принудительного завершения несохранённого пользовательского
документа. Сценарий остаётся неопределённым. Стабильная публикация отложена до
исправления и перепроверки очистки графики Undo, параметрических изменений, Drawing на актуальном кандидате, полного перезапуска
Fusion, Windows и остальных проверок сохранения/восстановления. См.
[нативный отчёт](validation/stability-native-2026-11-13.ru.md),
[заметки observer/восстановления](validation/observer-and-ax-recovery-2026-11-13.ru.md) и
[CJM и трассировку приёмки](validation/stable-release-cjm-2026-11-13.ru.md).

## Приёмка в Fusion

Для регрессии повторного сохранения при создании Drawing и управления
индивидуальной/общей видимостью выполните проверки из
[Видимость, сохранение определений и Drawing](visibility-and-drawing.ru.md).

Используйте тестовые модели. Проверьте установку и жизненный цикл команды, выбор и отмену, типы измерений, единицы и перемещение камеры, трансформированные и вложенные экземпляры и работу с несколькими документами. На macOS и Windows проверьте сохранение, Save As, отмену, неудачное сохранение, закрытие и повторное открытие, включая полный перезапуск Fusion. Для каждого пути сохранения остановите аддон и проверьте повторно открытые файлы визуально, а также по счётчикам групп. Приёмка всех путей сохранения и повторного открытия с CustomGraphics **не завершена**; не сохраняйте ценные модели при работающем аддоне. См. [заметки о безопасности Fusion](fusion-safety.ru.md).

Автоматизация релизов и неизменяемые теги описаны в [правилах выпуска](../.github/RELEASE_POLICY.ru.md). Mesora распространяется на условиях PolyForm Noncommercial 1.0.0; коммерческое использование за пределами разрешённых случаев требует отдельного соглашения.
