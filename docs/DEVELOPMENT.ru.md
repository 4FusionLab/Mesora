# Разработка Mesora

[English](DEVELOPMENT.md)

`Mesora/Mesora.py` содержит команду Fusion и обработку жизненного цикла событий; `Mesora/renderer.py` отвечает за графику, а `Mesora/dimensions/` — за логику измерений и размещения. Каталог `dimensions/` в корне сохранён как исторический автономный код; поставляемый пакет — `Mesora/`.

## Автономные проверки и пакет

```sh
python3 scripts/check_project.py
python3 -m unittest discover -s tests -v
python3 scripts/build.py --version 1.0.0
```

Сборщик создаёт детерминированный ZIP и SHA-256 в `dist/`. Версия манифеста записывается в архив без изменения файлов рабочего каталога. CI проверяет Linux, macOS и Windows, но не запускает Fusion.

## Статус кандидата и сохранение определений

Текущие исходники — экспериментальный кандидат для проверки, а не принятый
стабильный релиз. Явное подтверждение команды сохраняет ссылки и настройки в
атрибутах модели через `dimensions/runtime_persistence.py`; значения
пересчитываются. Схема v2 поддерживает все текущие типы измерений и читает схему
v1. Неизвестные, повреждённые или будущие данные нельзя молча перезаписывать.
Автоматическое обновление модели использует `commandTerminated` и отложенный
custom event; нативная приёмка ещё не завершена. Загрузка определений при открытии
документа и запуске аддона теперь запрашивает отложенное восстановление с проверкой
событий и состояния; активация документа лишь продолжает существующий запрос,
а сохранение снимает его. Фактическая нативная доставка callback и автоматический
показ после штатного перезапуска аддона/повторного открытия ещё не подтверждены.
См. последний повторный прогон в нативном отчёте ниже; приёмка полного перезапуска
Fusion остаётся открытой. Независимый `scripts/native_acceptance_observer.py` —
инструмент разработки, не часть поставляемого аддона.

Проверка API Save As на macOS воспроизвела видимый постоянный размер CustomGraphics
после остановки Mesora и повторного открытия файла даже при нулевом счётчике групп
API. Очистка при UI save и ручной **Refresh Dimensions** не подтверждают
безопасность нормального сохранения и повторного открытия. Стабильный релиз
отложен до устранения дефекта, нативной приёмки Windows и проверки полного
перезапуска. См. [нативный отчёт](validation/stability-native-2026-11-13.ru.md) и
[CJM и трассировку приёмки](validation/stable-release-cjm-2026-11-13.ru.md).

## Приёмка в Fusion

Для регрессии повторного сохранения при создании Drawing и управления
индивидуальной/общей видимостью выполните проверки из
[Видимость, сохранение определений и Drawing](visibility-and-drawing.ru.md).

Используйте тестовые модели. Проверьте установку и жизненный цикл команды, выбор и отмену, типы измерений, единицы и перемещение камеры, трансформированные и вложенные экземпляры и работу с несколькими документами. На macOS и Windows проверьте сохранение, Save As, отмену, неудачное сохранение, закрытие и повторное открытие, включая полный перезапуск Fusion. Для каждого пути сохранения остановите аддон и проверьте повторно открытые файлы визуально, а также по счётчикам групп. Безопасность сохранения и повторного открытия с CustomGraphics **не подтверждена**, и недоступный сохранённый размер уже воспроизведён; не сохраняйте ценные модели при работающем аддоне. См. [заметки о безопасности Fusion](fusion-safety.ru.md).

Автоматизация релизов и неизменяемые теги описаны в [правилах выпуска](../.github/RELEASE_POLICY.ru.md). Mesora распространяется на условиях PolyForm Noncommercial 1.0.0; коммерческое использование за пределами разрешённых случаев требует отдельного соглашения.
