# Видимость, сохранение определений и Drawing

[English](visibility-and-drawing.md)

**Статус: экспериментальный кандидат для проверки; стабильный релиз отложен.**
Undo воспроизвёл дублирование графики; нужны исправление очистки и нативная перепроверка.
Штатная GUI-проверка macOS подтвердила очистку и проверенный путь сохранения,
повторного открытия и редактирования без Mesora: при остановленном аддоне размеров
не было. Запуск Mesora восстановил определения, видимость, смещения и актуальные
значения. Прежний постоянный артефакт получен в другом пути загрузки Python/API и
не доказывает неисправность текущего штатного пути GUI-сохранения. Пока остаются
непройденные проверки, используйте тестовые документы. См.
[нативные доказательства](validation/stability-native-2026-11-13.ru.md).

У каждой строки измерения есть глазик. Он скрывает или показывает размер,
сохраняя ссылки на геометрию, тип и смещение. Перечёркнутый глазик означает, что
строка скрыта. Скрытые измерения можно редактировать.

Глазик рядом с **+**, **−** и корзиной скрывает или показывает весь набор. Он
сохраняет настройки отдельных строк: при повторном показе набора индивидуально
скрытые размеры остаются скрытыми. Изменения сразу видны в предпросмотре;
**OK** записывает подтверждённые ссылки на геометрию, типы измерений, смещения и
видимость в атрибуты модели. **Cancel** отменяет черновик и возвращает
подтверждённую видимость. Значения пересчитываются по актуальной геометрии, а не
сохраняются. Неподдерживаемые или повреждённые определения не перезаписываются молча.

Автообновление реализовано через `commandTerminated` с последующим custom event
в разрешённом потоке Fusion. Применение глазиков через GUI прошло проверку на
macOS-фикстуре. Undo/Redo восстанавливали метаданные видимости, но Undo вернул
неотслеживаемую группу графики, а отложенная перерисовка добавила вторую: реально
две группы при одной в State. Графическая приёмка Undo не пройдена; нужны
исправление очистки и повторная нативная проверка. Параметрические изменения и
полное восстановление также требуют приёмки; реализация и автономные тесты не подтверждают все нативные пути.

Кандидат также реализует загрузку определений при открытии документа и запуске
Mesora. Показ запрашивается через отложенный custom event; активация может
продолжить уже существующий запрос от открытия/запуска, а проверки рабочей среды,
активного документа и команды ограничивают создание графики. Сохранение снимает
ожидающий запрос восстановления. Штатный запуск/повторное открытие на macOS
восстановили два определения, скрытую строку, смещения и актуальную длину ребра
после изменения геометрии без Mesora. Независимый штатно запущенный observer
подтвердил доставку custom event и реальные callback сохранения. Прямой импорт
observer через MCP не подтвердил callback и не доказывает их отсутствие у штатного
аддона. См. [нативные доказательства](validation/stability-native-2026-11-13.ru.md);
приёмка полного перезапуска Fusion не выполнена.

Когда срабатывает событие сохранения через UI, Mesora удаляет отслеживаемую
графику перед сохранением. Она намеренно не пересоздаётся в `documentSaved`: это
снова помечало модель изменённой и могло вызывать повторное сохранение при создании
Drawing. После сохранения откройте Mesora или нажмите **Refresh Dimensions**,
чтобы вернуть размеры. Сама активация документа не создаёт нового запроса
восстановления: Drawing может активировать исходную модель в ходе создания. Она
может лишь продолжить существующий запрос от открытия/запуска. Активация рабочей
среды не пересоздаёт графику. Обработчик камеры не меняет графику модели в Drawing и во время
переключения рабочих сред.

Штатные GUI Save и Save As подтвердили очистку; отмена сохранила размеры.
Проверенный файл открывался без размеров при остановленной Mesora, оставался
доступен для изменения и сохранения и восстанавливал актуальные измерения после
запуска Mesora. Ручное обновление после сохранения остаётся обходным путём.
API Save/Save As со штатным жизненным циклом, изоляция копии и остальные пути
восстановления требуют отдельной приёмки. Прежний файл с постоянным артефактом —
историческое доказательство из другого пути загрузки/API; одного нулевого счётчика
групп API по-прежнему недостаточно для подтверждения отсутствия размеров в файле.

## Проверка

Используйте новую тестовую модель на каждой поддерживаемой ОС. Для каждого шага
фиксируйте результат и доказательство; сам список не означает прохождение проверок.

1. Создайте два измерения. Скройте одно: графика исчезает, строка, геометрия, тип
   и смещение остаются. Измените смещение скрытого измерения.
2. Скройте и покажите весь набор. Индивидуально скрытый размер остаётся скрытым.
3. Нажмите **OK**, откройте Mesora снова и проверьте оба глазика. Покажите скрытую
   строку и нажмите **Cancel**: прежняя видимость должна сохраниться.
4. Примените глобальное скрытие, откройте команду и включите показ. Настройки строк
   должны сохраниться. Удалите скрытую строку и добавьте новую.
5. Измените связанную геометрию, выполните Undo и Redo. Проверьте пересчёт значений
   и размещения; потерянные/неоднозначные ссылки не должны показывать старые размеры.
6. Отдельно проверьте UI Save, API save и Save As с показанными размерами:
   очистку, отсутствие изменений после сохранения и явный **Refresh Dimensions**.
7. Остановите Mesora, закройте и откройте модель; затем полностью перезапустите
   Fusion и откройте её снова. Кроме счётчика API, визуально проверьте отсутствие
   постоянных размеров. Запустите Mesora и проверьте определения, смещения и оба
   уровня видимости.
8. При показанных размерах создайте Drawing. Должны открыться лист и команда
   Base View, без бесконечного роста версий исходной модели.
9. Вернитесь в модель и проверьте измерения и видимость. Проверьте отмену и ошибку
   сохранения/закрытия без потери или перезаписи определений.

Очистка графики Undo с перепроверкой, параметрические изменения, Drawing на
актуальном кандидате, Windows, полный
перезапуск Fusion и оставшиеся пути API-сохранения/восстановления пока препятствуют
стабильному релизу. См. [ограничения Fusion](fusion-safety.md) и
[продуктовую матрицу приёмки](validation/stable-release-cjm-2026-11-13.ru.md).
