# Политика безопасности

[English](SECURITY.md)

Не публикуйте уязвимости, секреты, лицензионные ключи, модели клиентов и необезличенные диагностические журналы в открытых обращениях.

Используйте закрытую отправку отчётов об уязвимостях GitHub для этого репозитория, если она включена, либо свяжитесь с сопровождающим проекта через организацию 4FusionLab в частном порядке. Укажите затронутые версии, шаги воспроизведения и последствия, не публикуя конфиденциальные материалы.

При сборке намеренно отклоняются файлы, похожие на содержащие секреты, и символические ссылки. Эта проверка не заменяет ревью кода или реальную проверку в Autodesk Fusion.
