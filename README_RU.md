# Mesora

Mesora — экспериментальный аддон Autodesk Fusion для информационных 3D-размеров.
Откройте Design → Solid → Inspect → Mesora — Add Dimension и последовательно выбирайте геометрию, чтобы заполнить таблицу измерений. Две точки образуют расстояние; для каждой строки можно выбрать совместимый тип измерения. В том же меню доступны показ, обновление и очистка размеров. Используйте только тестовые документы.

Для MVP определения размеров хранятся только в памяти. Аддон намеренно не записывает
их в `Design.attributes`: при закрытии документа или остановке аддона они теряются.
Создание и удаление CustomGraphics может пометить документ изменённым. Из-за бага
Fusion графика, присутствующая при сохранении, может стать неудаляемой. Удаление перед
сохранением и восстановление после него реализованы, но **не проверены сохранением и
повторным открытием** и не дают гарантии безопасности. Для испытаний используйте
только тестовые документы; пока не сохраняйте их при включённой сборке.

Исходники аддона находятся в `Mesora/`. Автономные тесты запускаются командой:

```sh
python3 -m unittest discover -s tests -v
```

На macOS Fusion проверены отдельные измерения и прямое создание/удаление графики.
Интерактивный сценарий команд, события, сохранение, трансформации компонентов и
Windows ещё требуют проверки. Подробности — в [заметках](docs/fusion-safety.md).

## Установка

Соберите архив командой `python3 scripts/build.py --version 1.0.0` и распакуйте его в каталог AddIns Fusion: файлы `Mesora.manifest` и `Mesora.py` должны находиться непосредственно в папке `Mesora`. Затем запустите Mesora в диалоге Add-Ins. Остановка или перезапуск аддона удаляет сеансовые размеры.

Лицензия для распространения пока не выбрана. См. [заметки о лицензировании](docs/LICENSING.md).
