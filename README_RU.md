## Измерения в контексте модели

Откройте **Design → Solid → Inspect → Mesora — Add Dimension**, выбирайте геометрию и собирайте таблицу измерений. У строк есть сеансовые идентификаторы, например `m1`: можно изменить геометрию, выбрать совместимый тип измерения, настроить отступ и удалить строку. Подтвердите команду, чтобы показать размеры. В меню Mesora также доступны показ и скрытие, обновление и удаление размеров.

В зависимости от выбранной геометрии доступны **Distance**, **Angle**, **Edge Length**, **Radius**, **Diameter**, **Area** и **Perimeter**. Для расстояния и угла выбираются два совместимых объекта, для остальных типов — один поддерживаемый объект. Доступные варианты зависят от выбора; неподдерживаемые сочетания отклоняются.

## Установка и первый запуск

1. Скачайте `Mesora-1.0.0.zip` со страницы [экспериментального релиза](https://github.com/4FusionLab/Mesora/releases/tag/v1.0.0) и распакуйте архив в постоянную папку.
2. В Fusion откройте **Utilities → Scripts and Add-Ins → Add-Ins**. Нажмите **+ → Script or add-in from device** и выберите папку `Mesora` с файлами `Mesora.py` и `Mesora.manifest`.
3. Выберите **Mesora → Run**. При желании включите **Run on Startup**; пока аддон включён, учитывайте предупреждение выше.
4. Откройте тестовую модель и выберите **Design → Solid → Inspect → Mesora — Add Dimension**. Укажите один или два объекта для строки, проверьте совместимый тип и предпросмотр, затем подтвердите команду.

Не перемещайте распакованную папку, пока Fusion использует аддон. Для готового архива отдельная установка Python не нужна.

## Статус и ограничения

- Измерения существуют **только в текущем сеансе**. Определения хранятся в памяти и намеренно не записываются в `Design.attributes`; при закрытии документа или остановке аддона они теряются.
- Создание или удаление CustomGraphics может пометить документ изменённым. Сохранение и повторное открытие не проверены; предупреждение выше действует и после очистки графики.
- На macOS Fusion опробованы измерения без записи и прямое создание и удаление графики. Команда проверялась на временной модели с программными событиями выбора и подтверждением в интерфейсе. Физический выбор мышью, другие события, внешний вид и поворот, трансформированные и вложенные экземпляры, а также Windows ещё требуют проверки. Автономные тесты не подтверждают приёмку в Fusion.
- В манифесте заявлены Windows и macOS; это не подтверждает нативную проверку на обеих системах.

## Разработка и поддержка

Исходники аддона находятся в `Mesora/`. Автономные тесты и локальная сборка:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_project.py
python3 scripts/build.py --version 1.0.0
```
