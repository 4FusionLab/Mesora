# Security policy

Please do not publish vulnerabilities, secrets, license keys, customer models, or unredacted diagnostic logs in public issues.

Use GitHub's private vulnerability reporting for this repository when enabled, or contact a repository maintainer privately through the 4FusionLab organization. Include affected versions, reproducible steps and impact, without posting sensitive artifacts.

The project intentionally rejects likely secret files and symlinks during packaging. This check is not a substitute for code review or real Autodesk Fusion testing.
